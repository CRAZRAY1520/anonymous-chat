# 畫面設計

這份文件整理階段一的畫面設計結果,做前端時照著實作。畫面的元素與行為以 `docs/architecture.md` 第 7 節為準,這份文件補上「長什麼樣子」。

設計稿(8 個畫面,可以放大縮小對照):https://claude.ai/artifact/6oDoYP6xx61gEZuS2NXVAF

這個連結是私人的,只有你自己打開得了。設計稿裡的間距與尺寸,以下面的數值為準。

## 1. 整體風格

深夜公共空間的感覺:安靜、低調,像凌晨的公車站。只做深色版。

- 深藍黑底,不用純黑。
- 唯一的強調色是一盞「路燈」般的暖琥珀色,只用在代號、送出按鈕、主要按鈕和少數提示上,不要大面積使用。
- 其餘文字用灰藍色系,讓畫面保持安靜。
- 圓角偏大(14 到 22px),讓畫面柔和。
- 設計稿裡所有按鈕和可點的區域最小高度 44px,手機上好按。

## 2. 設計變數

實作時請把這些值定義成 CSS 變數,不要在各處寫死色碼。

### 顏色

| 變數 | 色碼 | 用在哪裡 |
|---|---|---|
| `--bg` | `#0D1017` | 整個頁面的底色 |
| `--panel` | `#141923` | 輸入框、名單面板、側邊欄 |
| `--line` | `#262E3D` | 所有分隔線與外框 |
| `--text` | `#DDE1E8` | 一般文字 |
| `--muted` | `#8791A3` | 次要文字:時間、說明、字數 |
| `--muted2` | `#6B7385` | 系統提示(進來了、離開了) |
| `--lamp` | `#E9B872` | 強調色:自己的代號、主要按鈕、提示 |
| `--bubble` | `#1B2230` | 別人訊息的底色 |
| `--mine` | `#2E2618` | 自己訊息的底色 |
| 錯誤紅 | `#F08A8A` | 輸入錯誤的邊框與文字 |
| 線上綠點 | `#7BC796` | 「線上 N 人」旁的小圓點 |
| 斷線警示底 / 邊 | `#251E10` / `#3B2F18` | 斷線提示條 |
| 停用的按鈕 | 底 `#3A3326`,字 `#8F7B55` | 送出鈕、進入鈕在不能按時 |

### 代號顏色(`color.js` 使用)

每個代號經過雜湊後,對應到下面這組顏色中的一個,所以同一個代號永遠是同一種顏色。這組顏色在深色底上都夠清楚:

`#85CDCA` `#C3A6E0` `#F2C879` `#9BC995` `#8EB8F0` `#EF9AA8`

設計稿只用了前三個,後三個是我補的,沒有放進畫面看過。**自己的代號永遠用 `--lamp` 琥珀色**,不從這組顏色裡取。其中 `#F2C879` 和琥珀色偏接近,實作後如果覺得難分辨,可以換掉。

### 字體

- 中文與英文都用 **Noto Sans TC**(字重 400、500、700),從 Google Fonts 載入,字體失敗時退回系統預設字體。
- 輸入頁大標題 32px / 700;聊天室頂部名稱 16px(手機)、18px(電腦)/ 700。
- 訊息內容 15px,行高 1.55 到 1.6。
- 代號與時間 12px。系統提示 12px。字數與操作說明 11 到 12px。

## 4. 各畫面的設計細節

### 4.1 輸入代號(A1、A2、A3、C)

- 內容垂直置中,左右留白 28px。
- 頂部有一團很淡的琥珀色光暈(漸層圓形),加上標題上方一顆發光的小圓點,是整個畫面唯一的裝飾。聊天室已滿時,圓點與光暈都變暗,表示「燈不亮」。
- 輸入框高 52px,右側顯示字數(例如 `2/12`)。
- 錯誤提示區固定保留一行高度,有沒有錯誤文字,版面都不會跳動。
- 主要按鈕高 52px,琥珀色底、深色字。
- 「重試」按鈕是琥珀色外框、透明底,表示它不是主要動作。
- 連線中的輸入框與按鈕都要設成真正的 `disabled`,避免重複送出。
- 畫面最下方有一行小字連結「原始碼:https://github.com/CRAZRAY1520/anonymous-chat」,12px,灰色、有底線,滑過變琥珀色,點了在新分頁打開。窄螢幕上字級隨寬度縮小(最小 10.5px)以維持一行。只放在輸入代號畫面,「聊天室已滿」與聊天室畫面不放。

### 4.2 聊天室頂部列

- 手機:左邊是發光小圓點加「匿名聊天室」,右邊是「線上 N 人 ▾」藥丸按鈕和「離開」文字按鈕。名單展開時,藥丸邊框變琥珀色,箭頭改成 ▴。
- 電腦:左邊同上,右邊只有「離開」按鈕。線上人數在右側名單上方顯示,頂部不重複放。

### 4.3 訊息列表

- 訊息由下往上堆疊,列表本身是 `role="log"`、`aria-live="polite"`。
- **別人的訊息**:靠左。上方一行是代號(用它自己的顏色、粗體)加時間(`--muted`),下方是訊息框,左上角圓角較小,其餘 16px。
- **自己的訊息**:靠右。上方一行順序反過來,時間在前、代號在後,代號顯示成「小明(你)」,用琥珀色。訊息框用 `--mine` 底色,右上角圓角較小。
- 訊息框最大寬度:手機 80%,電腦 75%。長字串要能換行(`word-break: break-word`)。
- **系統提示**:置中的灰色小字,例如「阿凱 進來了」。沒有底色、沒有外框,和真人說的話明顯不同。
- **舊訊息變淡**:整個訊息列表的上緣加一層遮罩,離上緣越近越透明。手機約 120px,電腦約 140px。這是純視覺效果,訊息仍然存在,捲動也不受影響。
- 電腦版訊息區置中,最大寬度 760px,左右各 32px 內距。
- 新訊息要有淡入效果。使用者系統若設定了「減少動態效果」,就不要淡入。

### 4.4 「有 N 則新訊息 ↓」按鈕

- 只在使用者往上看舊訊息、此時又有新訊息時出現。
- 放在訊息區底部、水平置中,浮在訊息上方。
- 藥丸形狀,琥珀色外框與文字,深琥珀色底,內含向下箭頭圖示。
- 按下去捲到最底並消失。

### 4.5 手機名單面板(B2)

- 點「線上 N 人」展開,蓋在訊息區上方,距頂部列下緣 8px,左右各留 12px。
- 面板外的部分壓暗(半透明黑色),點面板外或再點一次按鈕就關閉。
- 面板內每一列高 44px,左邊是該代號顏色的圓點,右邊是代號(同色、粗體)。自己那一列有深琥珀色底,右側標示「你」。

### 4.6 輸入區

- 手機:圓角輸入框(高 44px 起)加一顆 44px 的圓形送出鈕,送出鈕是琥珀色底、向上箭頭。電腦版稍大(48px)。
- 內容是空白時,送出鈕變灰並設成 `disabled`。
- 輸入框下方一行:左邊放提示,右邊放「還能輸入 N 字」。
  - 左邊的提示平常是空的。送太快時顯示「送太快了,等一秒再送」,用琥珀色。
  - 電腦版左邊平常顯示「Enter 送出 · Shift+Enter 換行」。手機版不顯示這句(手機 Enter 是換行)。
- 輸入區固定在畫面底部,手機鍵盤彈出時不能被遮住。

### 4.7 斷線提示條與空狀態(B3)

- 斷線時,頂部列下方出現一條琥珀色系的提示條,內含轉圈圖示與「連線中斷,嘗試重新連線…」,`role="status"`。重連成功後消失,並在訊息列表插入一行系統提示「已重新連線,中斷期間的訊息看不到」。
- 沒有任何訊息時,訊息區置中顯示發光小圓點、「還沒有人說話」、「這裡說的話,聊完就不見了。先打聲招呼吧。」。收到第一則訊息或第一個系統提示後,空狀態消失。

### 4.8 電腦版版面(B4)

- 左右兩欄:左邊是聊天主體(頂部列、訊息區、輸入區),右邊是 280px 寬的線上名單側邊欄,背景用 `--panel`,左側有一條分隔線。
- 側邊欄頂部是綠點加「線上 N 人」,下面是名單,每列高 44px,樣式與手機名單面板相同。
- 這個畫面的整體寬度是流動的,最小要能撐到手機寬度。手機寬度(約 640px 以下)時,側邊欄收起來,改用 4.2 與 4.5 的手機版做法。

## 5. 設計稿沒有畫到的部分

實作時請按上面的規則補上,不需要另外設計稿:

- **重新連線成功的那一行系統提示**:樣式同其他系統提示,只是文字不同。
- **連不上 Supabase、專案被暫停這類失敗**:沿用 A2 的錯誤提示區,顯示「連線失敗,請稍後再試」。
- **進入畫面時的輸入驗證錯誤**:代號空白或超過 12 字,同樣用 A2 的紅框加錯誤提示區,文字依原因而不同。
- **分頁標題未讀數**:不屬於畫面,在 `ui.js` 裡更新 `document.title`,格式為「(3) 匿名聊天室」。
- **電腦版名單上限與捲動**:名單超出側邊欄高度時,側邊欄內部捲動。

## 6. 設計稿的限制

- 這是靜態設計稿,只展示各種狀態,按鈕沒有實際功能。
- 我沒有在手機或不同瀏覽器上檢查過排版。實作完成後,請依架構文件第 13 節階段一的清單實際驗證,尤其是手機鍵盤彈出時輸入框的位置。
- 設計稿的字體從 Google Fonts 載入。如果網路不通,會退回系統預設字體,字寬可能略有不同。
